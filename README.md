# Weather App with TTS

Interactive weather dashboard built with a React + Vite frontend and a Python FastAPI backend. The app shows daily and hourly forecasts (Open-Meteo), interactive charts, location search (Google Places), and Text-To-Speech generated by a Gemini-based formatter and ElevenLabs voice synthesis.

**Tech stack:**
- Frontend: React, Vite, Chart.js, @react-google-maps/api
- Backend: FastAPI (Python), Open-Meteo API, ElevenLabs (TTS), Google GenAI (formatting)

**Features**
- Search for locations using Google Places
- Automatic geolocation on load
- Daily and hourly weather (up to 16 days) from Open-Meteo
- Interactive line charts for temperature, precipitation, visibility, pressure, wind, etc.
- TTS: backend formats a weather script (Gemini) and streams audio via ElevenLabs
- Visual effects: WebGL aurora background and icon-based weather card

**Quick start**

Prerequisites:
- Node.js (16+ recommended)
- Python 3.10+
- pip
- Google Maps API key (Places library)
- ElevenLabs API key and Google GenAI (Gemini) API key for TTS formatting

1) Install and run the backend

```bash
cd backend
python -m venv .venv
# On Windows (PowerShell)
.\.venv\Scripts\Activate.ps1
# On macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
# Additional Python deps referenced in backend/main.py
pip install python-dotenv elevenlabs google-generativeai

# Run the backend (default host 127.0.0.1 port 2137)
python main.py
# or using uvicorn
uvicorn main:app --reload --host 127.0.0.1 --port 2137
```

2) Install and run the frontend

```bash
cd ..
npm install
npm run dev
```

Open the app in your browser at the address `http://localhost:5173` (Vite default) and ensure the backend is running at `http://127.0.0.1:2137`.

**Environment variables**
- Frontend (project root `.env`):

```
VITE_GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

- Backend (create `backend/.env`):

```
ELEVENLABS_API_KEY=your_elevenlabs_api_key
GEMINI_API_KEY=your_gemini_api_key
```

Note: `backend/requirements.txt` currently contains the core server packages (`fastapi`, `uvicorn`, `requests`) but `main.py` imports additional packages (`python-dotenv`, `elevenlabs`, Google GenAI client). Install the listed extras as shown above.

**API Endpoints**
- `GET /` — health check, returns `{ "message": "Api connected" }` ([backend/main.py](backend/main.py))
- `GET /daily-forecast?lat={lat}&lng={lng}` — returns daily forecast JSON from Open-Meteo
- `GET /hourly-forecast?lat={lat}&lng={lng}&option={option}` — returns hourly forecast for chosen metric (e.g., `temperature`, `quantityOfWater`, `visibility`, `pressure`, `windSpeed`)
- `GET /formatTTS?text={text}` — formats a short presenter-style weather text (uses Google GenAI)
- `GET /tts?text={text}` — streams MP3 audio synthesized by ElevenLabs

Example cURL:

```bash
curl "http://127.0.0.1:2137/daily-forecast?lat=52.2297&lng=21.0122"
```

**How it works (high level)**
- Frontend (`src/`) fetches forecasts from the backend and renders cards and charts. See [src/App.jsx](src/App.jsx) and [src/Dashboard.jsx](src/Dashboard.jsx).
- The backend (`backend/main.py`) proxies Open-Meteo calls, formats presenter text with Google GenAI, and streams audio with ElevenLabs.

**Files of interest**
- [backend/main.py](backend/main.py) — backend API and TTS endpoints
- [src/App.jsx](src/App.jsx) — main React app wiring
- [src/SideBar.jsx](src/SideBar.jsx) — location search and options
- [src/ChartCard.jsx](src/ChartCard.jsx) — hourly data fetching and chart logic
- [src/Header.jsx](src/Header.jsx) — TTS playback integration
